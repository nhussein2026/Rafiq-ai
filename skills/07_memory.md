# Focused memory extraction

- Model proposes only small, user-relevant facts: goal, preference, dated event, or requested follow-up.
- Do NOT persist raw transcripts indefinitely; keep short, disclosed retention and offer access/delete.
- Explicitly ask before saving sensitive facts about health, intimate relationships, addiction, faith practice, or third parties.
- Record `consent_scope`, `source_message_id`, `review_status`, `expires_at` and `user_id` for approved facts.
- The user can inspect, correct, revoke, or delete memories, including queued follow-ups based on erased content.
- Never infer religious observance, diagnose mental illness or invent remembered details.
- Outbound notifications should use neutral preview text if sensitive topic details might appear on lock screen.
